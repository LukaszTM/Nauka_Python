# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Projekt

Mały projekt do nauki Pythona (`hello.py` – wypisuje imię i aktualną datę/czas). Brak zależności, testów, lintera i systemu budowania. Nie jest repozytorium git.

Zasady współpracy z użytkownikiem (nauka pod rolę Junior QA, nie pisz rozwiązań za niego, pytaj przed pokazaniem kodu, tłumacz po polsku) są w nadrzędnym pliku `../CLAUDE.md` i obowiązują także tutaj.

## Uruchamianie

Środowisko wirtualne jest w `.venv` (używane przez PyCharm – katalog `.idea`).

```
.venv\Scripts\python.exe hello.py
```
